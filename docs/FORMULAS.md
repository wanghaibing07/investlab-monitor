# 公式、时序与研究边界

## 目标与风险来源

目标权重`w=(0.6,0.4)`；近似单日纳指敞口`0.6+3×0.4=1.8`。多日表现按ETF实际收益连乘计算。两只基金主要承担相同的纳指风险，TQQQ放大单日变化。

组合收益`r_p,t = w_Q,t-1 r_Q,t + w_T,t-1 r_T,t`，现金在研究中的收益假设为0。组合波动`σ_p = sqrt(w'Σw)`，年化按252个交易日。方差贡献份额`RC_i = w_i(Σw)_i / (w'Σw)`；风险平价调整各资产的风险分配，分散程度受资产相关性限制。

## 分步配置规则

QQQ高于SMA200的103%开启趋势，低于98%关闭；区间内延续前一状态。QQQ近20日对数收益样本标准差乘`sqrt(252)`得到波动。

趋势开启且波动低于25%时，TQQQ从**最后确认持仓**向40%最多增加5个百分点；25%—35%暂停增加；趋势关闭或波动达到35%时复核退出TQQQ。QQQ按60%及容差维护。建议以最近确认持仓为起点；账户记录更新后再计算下一步。

## 研究对照

| 方法 | 计算原则 |
|---|---|
| 固定60/40 | 月度信号、下一交易日收盘恢复目标 |
| 风险平价 | 求各资产方差贡献相同；二资产解析关系`w_Q σ_Q = w_T σ_T` |
| 波动目标 | `risk_weight = min(cap, target_vol / estimated_vol)`；其余现金 |
| 时间序列动量 | 本资产过去252交易日收益为正才参与，再按波动控制 |
| 均值回归 | 标准化偏离、残差AR(1)、恢复半衰期，配合趋势与最长持有期限 |
| 宏观四因子 | `r = α + β'Δfactor + ε`；用实际利率、通胀预期、美元和信用利差解释风险 |

AR(1)形式`x_t = a + φ x_t-1 + ε_t`。当`0<φ<1`时，半衰期`-ln(2)/ln(φ)`表示当前模型下的恢复时间。拟合描述历史关系，未来回归情况通过后续数据评估。

概率事件固定为：未来20交易日，QQQ某日收盘较预测原点下跌至少10%。用Brier误差`mean((p-y)^2)`与历史频率基准比较。训练标签必须在预测原点前已经完整到期。概率结果用于研究对照，仓位按配置规则计算；评估同时保留优于和低于基准的结果。

联合移动区块重采样同时抽取QQQ/TQQQ收益，保留部分短期连续性与相关性。模拟路径中的比例表示在当前数据与假设下的模型频率，实际市场概率须通过后续观察评估。

宏观数据使用当前可取得的版本，适合解释敏感度和冲击。宏观择时收益验证需要当时可获得的历史发布数据；四因子作为解释变量，资产池仍为QQQ/TQQQ。

## 交易费用与执行顺序

收盘t产生目标，t+1收盘执行。原持仓先获得`t→t+1`收益，新仓位从`t+1→t+2`开始获得收益。复权价单位只是总回报会计单位，不是券商股数。

每边费用率`c`，调仓前资产价值`v_i`、总值`V`，调仓后净资本`E`满足：

`E + c Σ_risky |w_i E - v_i| = V`。

原引擎用二分法求解。独立复核按每个买卖符号区间直接解线性方程，并逐日重放已保存目标。该检查核对费用与净值记账。行情正确性由数据源核对检查，策略超额收益由独立的效果评价判断。

## 评估方法

开发使用过的历史数据按252交易日分段，检查不同时段的表现。固定代码、参数和数据截止日后，单独记录后续实际行情下的结果。评估保留窗口重叠情况、样本数量及全部结果；研究参数采用固定配置。
