# 公式、时序与研究边界

## 目标与风险来源

目标权重`w=(0.6,0.4)`；近似单日纳指敞口`0.6+3×0.4=1.8`。这描述单日变化近似，多日必须使用ETF实际收益连乘。两只基金不是两种独立风险。

组合收益`r_p,t = w_Q,t-1 r_Q,t + w_T,t-1 r_T,t`，现金在研究中的收益假设为0。组合波动`σ_p = sqrt(w'Σw)`，年化按252个交易日。方差贡献份额`RC_i = w_i(Σw)_i / (w'Σw)`；高相关资产之间风险平价不能制造分散收益。

## 既有人工分步配置

QQQ高于SMA200的103%开启趋势，低于98%关闭；区间内延续前一状态。QQQ近20日对数收益样本标准差乘`sqrt(252)`得到波动。

趋势开启且波动低于25%时，TQQQ从**最后确认持仓**向40%最多增加5个百分点；25%—35%暂停增加；趋势关闭或波动达到35%时复核退出TQQQ。QQQ按60%及容差维护。未确认交易时重复日报仍输出同一步。

## 研究对照

| 方法 | 计算原则 |
|---|---|
| 固定60/40 | 月度信号、下一交易日收盘恢复目标 |
| 风险平价 | 求各资产方差贡献相同；二资产解析关系`w_Q σ_Q = w_T σ_T` |
| 波动目标 | `risk_weight = min(cap, target_vol / estimated_vol)`；其余现金 |
| 时间序列动量 | 本资产过去252交易日收益为正才参与，再按波动控制 |
| 均值回归 | 标准化偏离、残差AR(1)、恢复半衰期，配合趋势与最长持有期限 |
| 宏观四因子 | `r = α + β'Δfactor + ε`；用实际利率、通胀预期、美元和信用利差解释风险 |

AR(1)形式`x_t = a + φ x_t-1 + ε_t`。只有`0<φ<1`时，半衰期`-ln(2)/ln(φ)`才有当前模型下的恢复含义。拟合关系不等于未来必然回归。

概率事件固定为：未来20交易日，QQQ某日收盘较预测原点下跌至少10%。用Brier误差`mean((p-y)^2)`与历史频率基准比较。训练标签必须在预测原点前已经完整到期。概率研究不决定仓位；未胜过基准时保留失败结果。

联合移动区块重采样同时抽取QQQ/TQQQ收益，保留部分短期连续性与相关性。模拟路径中的比例只是模型内部频率，不冒充现实市场的准确概率。

宏观数据当前不是历史发布版本，因此可解释敏感度和冲击，但不声称已验证宏观择时收益。四因子不会变成资产池中的国债或黄金。

## 交易费用与执行顺序

收盘t产生目标，t+1收盘执行。原持仓先获得`t→t+1`收益，新仓位从`t+1→t+2`开始获得收益。复权价单位只是总回报会计单位，不是券商股数。

每边费用率`c`，调仓前资产价值`v_i`、总值`V`，调仓后净资本`E`满足：

`E + c Σ_risky |w_i E - v_i| = V`。

原引擎用二分法求解。独立复核按每个买卖符号区间直接解线性方程，并逐日重放已保存目标。这样可以发现费用与净值记账差错，但不独立证明原始行情正确，也不能证明择时有超额收益。

## 验证纪律

历史已用于开发。252交易日分段是历史稳定性诊断，不称为从未看过的样本。固定当前代码、参数和数据截止日后，后续真实到达的行情才开始提供该版本的前瞻证据。窗口重叠、样本数量和失败结果都保留。研究参数不按本轮回测收益自动寻优。
