# 本地网页账户操作

InvestLab 的真实账户数据留在自己的电脑上。公开 Vercel 站点只展示虚构快照；没有账户输入 API、没有数据库与交易入口。

## 初次使用

安装 Python 3.11+ 和 InvestLab，建立私有运行目录：

```bash
investlab --home ~/.local/share/investlab init
investlab --home ~/.local/share/investlab serve --local-edit
```

然后在运行这条命令的**同一台电脑**打开 `http://127.0.0.1:8765/`。「今日判断」下面会出现「录入已确认账户估值」。

1. 输入估值日期、QQQ、TQQQ、QLD、现金的人民币金额（非负整数，零仓位填0），以及这份数据的来源。
2. 明确勾选本人已核对。点击「保存确认估值」，程序保存在私有 SQLite 数据库中，**不会生成买卖流水**。
3. 点击「用已保存行情计算」可以用本机已有行情重新计算。第一次使用真实账户时，通常需要点击「联网更新并核验行情」获取日线，再根据显示的数据日期和质量判断能否使用。
4. 「重新读取快照」或「刷新记录」只获取已保存数据，不会自动发出交易。

### 默认只读

普通 `serve` 依然只读，只有主动添加 `--local-edit` 才允许本地修改。两者都只监听 `127.0.0.1`，不允许从其他设备联网访问。**`--public-demo` 和 `--local-edit` 不能同时使用**。

编辑端保护包括：服务器启动时生成随机会话令牌、同源 Origin/Host 验证、禁止跨站 Fetch、仅接受 JSON、8 KiB 请求大小限制、显式 confirmed、数据库串行锁、账户追加记录与去重。请求失败不会伪造成功状态，页面不记录凭据。不允许把该服务通过反向代理直接公开到互联网；如需跨设备管理，应另外设计用户身份验证。

### Alpaca Paper Trading

`alpaca-paper-snapshot` 仍是只读、独立保存的美元模拟账户报告，不会自动变成真实人民币持仓，也不会提交交易。它与网页的「本人已确认估值」是不同的数据通道。

## 适用边界

- 这里填写的是估值，不是可证明的成交或平均成本；交易流水仍可用 `ledger-import` 导入。
- 改变估值后，必须点击重新计算才会更新策略判断。联网失败时旧报告不会被伪装成当日成功。
- 回测不验证未来收益；在研究页查看仓位敞口与模拟风险。
- 本地目录应限制其他系统用户读写；备份与数据库均可能包含个人账户信息。

## 额外的真实行情背景核对

若本地已有真实行情且配置了 Alpaca Paper Trading 凭据，可运行 `investlab --home ~/.local/share/investlab alpaca-quote-check` 查看最新本地交易日与 Alpaca IEX 日线的差异。它不改变原行情、报告或交易信号；`CONTEXT_AGREEMENT` 只是背景佐证，不是全市场独立结算价证明。细节见 [Alpaca 模拟账户文档](ALPACA_PAPER.md)。
