# InvestLab 私有云部署

在自己的 Vercel 项目中运行 InvestLab，随时查看投资组合、策略研究和历史报告。账户数据保存在独立的私有存储中，访问由 Vercel Authentication 保护。

**[项目首页](../README.md)** · [每日自动监控](VERCEL_DAILY_AUTOMATION.md) · [生产运行验证](CLOUD_RELIABILITY_ACCEPTANCE.md)

## 部署后可以做什么

| 页面 | 功能 |
| --- | --- |
| **资产总览** | 当前账户估值、QQQ / TQQQ / QLD / 现金比例、最新分析摘要 |
| **投资组合** | 持仓结构、目标配置与历史估值 |
| **策略与风险** | 趋势、波动、分步调整参考和风险指标 |
| **运行报告** | 行情日期、计算结果、质量检查及研究记录 |
| **账户与设置** | 更新已确认估值、查看恢复检查和每日运行状态 |

日常使用流程：**登录工作台 → 查看行情和账户 → 阅读策略分析 → 保存自己的决策记录**。

公开的 [InvestLab 演示](https://investlab-monitor.vercel.app/) 使用示例数据；本页面说明的是用于个人账户的私有部署。

## 技术组成

- **FastAPI + Vercel Functions**：提供网页与投资研究计算。
- **Vercel Authentication**：管理个人工作台访问权限。
- **私有 Vercel Blob**：保存账户、研究报告、历史版本和恢复所需快照。
- **Vercel Cron Jobs**：按美股交易日安排分析，并在后续窗口检查运行结果。
- **Python 研究引擎**：完成行情采集、数据检查、策略计算和审计。

账户估值由本人确认后保存。定时任务读取当前账户版本，在独立的数据副本上计算，并把研究结果和运行记录保存到私有存储。

## 部署步骤

1. Fork 或使用本仓库，创建 Vercel 项目，连接 `vercel-cloud` 发布分支。
2. 在 Vercel 开启 **Deployment Protection / Vercel Authentication**。
3. 连接私有 Blob，确认生产环境已配置 `BLOB_READ_WRITE_TOKEN`。
4. 检查 `CRON_SECRET`，并在生产环境设置 `INVESTLAB_CRON_ENABLED=true`。
5. 重新部署生产版本，检查页面和每日运行设置。
6. 登录后在「账户与设置」录入并保存本人确认的人民币估值，再运行一次在线核验。

`vercel-cloud` 由 GitHub Actions 根据经过检查的主分支生成，可在 [Actions](https://github.com/wanghaibing07/investlab-monitor/actions) 查看发布记录。

## 账户管理

第一次登录，填写 QQQ、TQQQ、QLD 和现金的人民币估值、估值日期与来源说明，创建自己的账户。以后可直接在「账户与设置」更新：

- 每次确认都会保存一份新版本，保留历史数据。
- 保存后系统重新读取账户信息，核对日期、金额与数据库完整性。
- 页面同时提供历史记录与最近两份快照的恢复检查。
- 交易流水与持仓估值分别管理，便于核对实际投资过程。

建议在一个浏览器中完成每次账户修改；页面会检查版本并提示刷新最新数据。恢复操作及独立备份的验收方法见 [生产运行验证](CLOUD_RELIABILITY_ACCEPTANCE.md)。

## 每日自动监控

私有云支持两段式自动化：

| 北京时间 | 运行内容 |
| --- | --- |
| 周二至周六 08:00–08:59 | 针对最新完整美股交易日更新行情、执行计算并保存报告 |
| 周二至周六 11:00–11:59 | 检查当天记录，按需要补跑并发送故障提醒 |

具体时间受 Vercel 计划调度精度影响；程序使用纽约时区及交易日历处理节假日和夏令时。

在「账户与设置」查看**是否启用、最近运行交易日、结果状态和邮件配置**。如需 QQ 邮箱提醒，可在 Vercel 的 Production 环境填写 SMTP 主机、邮箱和邮箱授权码；配置及测试步骤见 [每日自动监控](VERCEL_DAILY_AUTOMATION.md)。

投资组合长期参考为 **60% QQQ + 40% TQQQ**。系统展示趋势、仓位和风险依据，交易由账户持有人执行。

## 运行状态与检查

| 关心的问题 | 查看位置 |
| --- | --- |
| 账户是否正常读取 | 工作台「资产总览」或受保护的 `/api/account` |
| 最新行情和策略报告 | 「运行报告」或 `/api/latest` |
| 自动监控是否配置 | 「账户与设置」或 `/api/scheduler/status` |
| 最近两份账户快照能否恢复 | 「账户与设置」中的恢复检查 |
| 云端定时任务是否触发 | Vercel Cron Jobs 与对应部署日志 |

服务端还提供 `/api/status` 和 `/health` 用于运行排查。完整的市场数据、账户持久化、定时任务与故障通知验收标准集中在 [生产可靠性说明](CLOUD_RELIABILITY_ACCEPTANCE.md)。

## 安全与数据管理

- 通过 Vercel Authentication 管理私有访问者，按需要配置权限。
- 将账户快照、密钥和邮箱授权码保存在私有环境中。
- 使用私有 Blob 版本与恢复检查维护账户记录；关键备份可独立保存。
- 账户写入前核对当前版本，定时研究结果与人工确认估值分别保存。

更多使用方法见 [操作手册](OPERATIONS.md)、[研究方法](FORMULAS.md) 和 [每日任务指南](VERCEL_DAILY_AUTOMATION.md)。
