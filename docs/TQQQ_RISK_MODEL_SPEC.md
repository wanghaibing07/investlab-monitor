# TQQQ影子风险模型

收益率单位为小数，年化采用252交易日。QQQ生产20日波动按对数收益样本标准差计算，原C0保持原函数。

长期：原SMA200与103%/98%滞后缓冲。中期：SMA50、63日动量。短期：SMA20、连续3日方向、5/10日跌幅。波动：5日实现、20日对数、EWMA(lambda=0.94)、TQQQ自身20日波动。风险预算：60日实际ETF简单收益协方差，sigma=sqrt(252*w'Cov*w)。方差贡献w_i(Cov*w)_i/(w'Cov*w)。

C1：低于SMA20并连续3跌时，仅暂停TQQQ新增。C2：max(EWMA,5日波动)>20%且>1.5倍20日波动时暂停新增。C3：整组合按25%研究波动情景等比例缩放；另预登记15/20/25%。C4：C1+C2+C3。参数仅为冻结候选。

CVaR取最差ceil(5%*n)日简单收益均值；CDaR取最差5%逐日高水位回撤均值；水下期按交易日计数。指标是窗口估计，不是未来损失上限。60日组合风险回放假定日内固定权重，仅诊断协方差，与月度再平衡历史策略分开。

多日收益使用真实ETF序列连乘。合成3倍路径显著标为理想化情景，不能混入真实历史业绩。QQQ与TQQQ主要共享纳指风险，不构成两个独立风险来源。
