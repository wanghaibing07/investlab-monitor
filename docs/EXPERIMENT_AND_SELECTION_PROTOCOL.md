# 实验登记与选择

计算前排他创建experiment_registry.json，记录源码提交、代码/数据/参数哈希、策略、成本、执行、指标与否决标准。目录已经存在即拒绝。结果以新文件排他写入，不更新生产数据库或创建迁移。

110个预登记比较：5候选x2费用x3滑点=30；5候选x4额外执行x3滑点=60；3风险预算x(1动态规则+4固定对照)=15；5个事后15%波动标准化描述=5。前缀一致性与原C0回归是验证检查，单列计数，不作为新增调参。

接受草案在结果前固定：相对C0最差5%日收益改善至少10%，同时CAGR下降不超过3个百分点。即使满足，也只意味着历史诊断门槛通过，仍停在研究版。

固定参数无需训练拟合；252交易日分段用于时间稳定性诊断，删最后20日检验所有候选之前的净值不变。历史全部标HISTORIC_DIAGNOSTIC_ALREADY_SEEN。反弹窗口允许重叠且完整列出，不当独立样本。不新增20日概率模型或以重叠标签宣称盲测。

事后波动标准化依赖整个样本，只是描述性风险对照，不可称可交易风控路径。动态C3才使用每个当时60日协方差。未进行参数搜索；试验总数与全部结果公开给研究者。Deflated Sharpe在无法可靠估计选择偏差时不捏造数值。
