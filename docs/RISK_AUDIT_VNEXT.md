# 风险研究变更审计

新增独立 `shadow-risk` 命令。原 `run`、`review`、账户和邮件触发逻辑保持原接口。研究输出必须位于运行目录之外的新目录，拒绝覆盖。

风险分歧指生产TQQQ进入人工增加复核，同时QQQ跌破SMA20且最近3日连续下跌。它是两套规则的分歧，不是已证明的错误买点。C1只暂停新增，不取消C0退出。C2检查快速波动。C3/C4可缩减QQQ并留现金，只作未审批研究。

主要反例：过滤可能错过V形反弹；波动目标可能底部减仓；更高杠杆收益不等于择时能力；历史已见不等于前瞻。所有比较保留候选与失败，不自动选策略上线。

Windows原基线存在路径分隔符断言与未及时关闭SQLite句柄的旧测试兼容性问题。UTF-8模式是当前运行前提。Linux固定源码CI独立核实，不把Windows失败改写成通过。
