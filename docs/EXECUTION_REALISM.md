# 执行与成本假设

黄金基线：t收盘生成目标，t+1收盘假设成交。旧持仓先赚t到t+1收益；新持仓随后开始赚收益。C0两档原费用的每个净值点与交易列表必须完全一致。

额外模型：假设次日开盘（无OHLC时默认零隔夜跳空，仅作敏感性）、不利开盘跳空（买入方向QQQ+1%、TQQQ+3%，卖出反向，显式合成）、延迟一个交易日、每第20个调仓信号无法成交。延迟时保留单个待执行目标，不使用未来信号重写它。无法成交留下原因，无真实订单。

每边手续费15/50基点，额外滑点0/10/30基点。滑点用与换手成比例的附加资本损耗模拟，不声称真实券商报价。费用和滑点分别列账。ETF基金层成本已体现在实际回报中，不再扣一次。现金零息；税、汇率与真实价差待具体券商输入。

自融资：E+c*sum(abs(w_i*E-v_i))=V。沿用原求解器，核对净资本+费用=调仓前资本。实际股数、人民币盈亏和可执行金额需要完整确认账户，不由研究回测生成。
