# 行情来源契约

`QualifiedDailyBar`保留代码、交易日、供应商、feed、调整方式、原价、复权价、OHLC、公司行动、获取时间与原文SHA。没有原文或公司行动时维持DATA_LIMITED。

不接受未来日、非交易日、重复乱序、非有限正价格、非日线、残留分页token或期望日历缺口。异常跳变要求公司行动证据。原价冲突阻断，不覆盖另一供应商。复权价一致与否需要分红拆分口径解释，不能用原价相同认证复权历史。

Yahoo两个域名算一个供应商；IEX仅该交易所，不称全市场收盘；SIP无权限明确SOURCE_UNAVAILABLE。供应商资格校验不自动升级既有生产成功等级。历史研究继续使用归档行情，不在后台下载覆盖。

Alpaca连接器当前没有page_token入参，无法保证任意大区间自动分页；适配器对残留token必须拒绝。可按显式日期区间拆分并验证完整日历，不能静默少页。

官方接口：https://docs.alpaca.markets/us/reference/stockbars 。来源许可与代码MIT许可分别处理，本研究不新增订阅或再分发行情授权。
